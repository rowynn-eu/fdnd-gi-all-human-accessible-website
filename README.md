## Gebruik

De website is bedoeld voor ontwikkelaars, ontwerpers, en mensen die verantwoordelijk zijn voor overheidscommunicatie. Op de website kan je **open** en **rechtenvrije** iconen vinden, vergelijken en downloaden. Secundaire kan je ook illustraties vinden die de jij als gebruiker kan stijlen naar je eigen huisstijl. 

## Kenmerken
De website is gebouwd met [HTML](#HTML), [CSS](#CSS) en [JavaScript](#JavaScript), en bestaat uit zes pagina's. De inhoud van de website is vergelijkbaar, alleen wat netter opgeschreven. Het belangrijkste punt deze sprint gaat over het kleuren contrast, toegankelijkheid, en WCAG.
